# خطة تسويق أثر — React App

خطة التسويق السنوية لجمعية صناع الحياة الخيرية، كـ React app خفيف مبني بـ Vite.

## التشغيل

```bash
npm install
npm run dev
```

هيفتحلك السيرفر على `http://localhost:5173`.

للبناء النهائي (نسخة إنتاج جاهزة للنشر على أي استضافة استاتيك زي Netlify / Vercel / GitHub Pages):

```bash
npm run build
```

الناتج هيبقى في مجلد `dist/`.

## هيكل المشروع

```
src/
  data/                 كل المحتوى النصي والبيانات — عدّل هنا بس، مش في الكود
    segments.json       الحملات وفترات الراحة (تواريخ، أهداف، أسباب)
    principles.json      قواعد ترتيب الخطة (الأكورديون)
    teams.json           الفرق الأربعة: خط سير المحتوى + تركيز كل حملة
    devSkills.json       مهارات كل فريق (قسم تطوير الفريق)
    meta.json            ثوابت التقويم (أسماء الشهور، عدد الأيام)
    copy.json            كل نصوص الواجهة الثابتة (العناوين، الهيدر، الفوتر)

  components/            مكوّنات React، كل واحد مسؤول عن جزء واحد بس
    Header.jsx            اللوجو
    Hero.jsx               قسم المقدمة والإحصائيات
    WheelSection.jsx        الحاوية اللي بتربط العجلة + القائمة + كارت التفاصيل
    Wheel.jsx                رسم العجلة (SVG)
    PillNav.jsx              قائمة بديلة سريعة (خصوصًا للموبايل)
    DetailCard.jsx           كارت تفاصيل القطاع المختار
    PrinciplesSection.jsx    الأكورديون
    TeamsSection.jsx         تابات الفرق + الجدول
    DevPlanSection.jsx       خطة تطوير الفريق
    Footer.jsx

  utils/
    wheelMath.js          دوال حساب زوايا وأقواس العجلة (SVG) بعيدة عن React خالص

  App.jsx                 تجميع كل الأقسام مع بعض
  main.jsx                 نقطة الدخول
  styles.css               كل الـ CSS (متغيرات الألوان في الأول: --ink و --gold)

public/
  assets/logo.png          لوجو الجمعية
```

## إزاي تعدّل المحتوى

- عايز تغيّر تاريخ أو مدة حملة؟ افتح `src/data/segments.json` وعدّل `start` و`end` (أرقام أيام من ١ أغسطس، من ٠ لـ ٣٦٥) أو النصوص.
- عايز تضيف/تشيل فريق؟ عدّل `src/data/teams.json`.
- عايز تغيّر أي نص ثابت في الواجهة (عنوان، وصف قسم، ملاحظة الفوتر)؟ كله في `src/data/copy.json`.
- عايز تغيّر الألوان؟ أول ١٣ سطر في `src/styles.css` (داخل `:root`) فيهم كل الألوان الأساسية.

مفيش حاجة تانية محتاجة تتعدل في الكود عشان تحدّث المحتوى — الكومبوننتس بتقرأ من ملفات الـ JSON دي تلقائيًا.
